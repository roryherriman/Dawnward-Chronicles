## 1. What changed

## 2. Sweeps (new tests)

`tests/support/sweep.lua` builds a character with every kind of record (and, separately, a brand-new one) and walks every screen: Journal and its editor, Character profile, both readers and the Showcase, Story, every Chronicle tab with its New form, the reaction card, a confirmation dialog, every Settings page (Total RP 3 included), every Guide topic, the story import window and every setup page.

`tests/spec/ui_v101_sweep_spec.lua`:
- **Text size:** no visible text under `Style.MIN_TEXT` (13), with records and empty.
- **Clipping:** every visible button label fits its button (`Widgets.LabelFits`) and every one-line label of fixed width fits its width.
- **Themes:** for Classic Dawnward, Lightbound and Shadowbound, a window built in another theme with every screen opened and then switched paints every visible texture, line and font string *exactly* as a window built in that theme from the start (over 10 000 regions compared per theme); a mutation that leaves one label unregistered makes it fail. A further test cycles all three themes on every screen without an error.
- **Scale:** at window scale 0.7 and 1.4 every visible region on every screen keeps the anchors and size it has at 1.

`tests/spec/ui_v101_refinements_spec.lua` (13): long Story answers at three scales, the unbroken-word estimate, Showcase icons and states and the control bar, Character place after the callout goes, every Chronicle empty state and its action, Clear search, the reader empty states, the Story empty icon, the guide (sizes, labels fit, long results scroll, wheel, topic starts at the top, Done), no developer words on the ordinary Settings pages of a release build, Significance help, one style for side-panel notes.
Updated: `ui_character_v10_spec` (rotate line icons, mirrored paths), `ui_showcase_native_icons_spec` (runs on a client without line regions; the edgeless fallback), `ui_chronicle_spec` (Places empty title).

`python tools/check.py`: all checks ok, **1170 passed, 0 failed** (1148 before).

## 3. Remaining differences

| Element | Difference | Cause |
|---|---|---|
| Line icon ends and joins | Square ends, plain joins on the rotate arrows' circle | limit: 1.15.9 Line regions have no round caps |
| 1 px edges at scale 0.7 | A 1 px edge is 0.7 physical px; the client snaps textures to the pixel grid, so an edge can look uneven or vanish on some sides | limit (client pixel snapping); not changed without an in-game look (`SetSnapToPixelGrid` exists on textures but changing it blindly could blur every edge) |
| Story answer hint | The hint line is one line, cut by the client with "…" when longer than the card (the tooltip has it) | deliberate (v0.7: hints under answers) |
| Story answers longer than three lines | Cut at three lines (two in the fullest moments) with the whole answer on hover | deliberate: the card keeps its action row on screen |
| Guide | The topic list is the segment look, not the rail's nav look | deliberate: the guide is a panel over the content, like Settings' page switcher |
| Story empty state | Keeps its own layout (title, gold rule, body, summary) with the new icon, not the shared card | deliberate: it shares the moment card's frame and the summary line |
| Journal empty state | Unchanged (it is the reference the shared card copies); no action button, New entry is right above it | deliberate |
| Import window and Settings > Data say "bytes" | The story limit is counted in bytes (the edit box and Total RP 3 limits are byte limits; "characters" would be wrong for accented letters) | deliberate; `Core/StoryImport.lua` status line is outside this track |
| Minimap button tooltip | Title in the game's default tooltip colour, not the design's bright gold | not done: `UI/MinimapButton.lua` was outside this track's file list |
| Showcase ground shadow, lighting | As v10-character.md | limit |
