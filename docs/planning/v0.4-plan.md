# v0.4: The Living Chronicle (plan and status)

Goal: the first playable loop.

```
Gameplay event -> contextual reaction -> player decision -> personality development -> journal entry -> approved TRP3 update
```

## Audit of v0.3 (starting point)
- The core is pure Lua with a milestone registry (`Milestones`), a journal with retention, canon facts, six personality axes (0–20, private by default) and a projection that is the only way data leaves the core.
- Experimental TRP3 sync (PR #9) syncs public facts to an owned About block and public axes to owned traits, with backups, rollback, ownership by exact match, conflict detection and editor protection.
- The planning documents in `living-character/` already described moments, prompts, decisions and an evolution model. v0.4 follows them, with two deliberate changes: it uses the **existing six axes on 0–20** (not a new ±100 tendency set), and it has no separate mood yet.

## Decisions
1. **One `story` table per character** (`Core/StorySchema.lua`), added by an additive 3 → 4 migration. There is no second store: drafts are ordinary journal entries (`kind = "story"`).
2. **Event records hold verified data only.** Significance comes from explicit rules: quest level ≥ character level + 2, the first quest in a zone, every 5th or 10th level, the first death. There is no guessing.
3. **Templates are data and universal.** Each has a neutral fallback question and answers in opposite directions. Class flavour adds one answer with no effect. Tests scan all text for class, race, faction, city, deity, moral-label and gendered words.
4. **Selection is deterministic.** Specific templates (with `when`) come first; general ones take turns; recently used ones are skipped.
5. **Development is proposals.** Each is ±1, approved by the player (or automatic if chosen; still reversible), with at most 2 steps per axis per day. The baseline is kept. Manual edits are recorded too.
6. **Drafts are private until approved.** Only approved, important, public story entries reach TRP3, and only as titles in Dawnward's own section.
7. **Calm moments only.** SafeTime checks on events (leaving combat, reviving, resting, arriving in a zone) and never polls. The card can be switched off.
